Led the training session covering sequence analysis workflows, data structures, and algorithms within [scikit-bio](https://github.com/scikit-bio/scikit-bio), a fundamental Python library for biological omics data. The tutorial walked participants through workflow on using protein embeddings for sequence analysis within the library.
